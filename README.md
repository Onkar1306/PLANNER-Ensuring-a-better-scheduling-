# PLANNER-Ensuring-a-better-scheduling-
This Time Management and Task Allotment app enhances productivity by organizing tasks, setting priorities, and managing schedules. Key features include customizable task lists, automated reminders, and calendar integration. Advanced algorithms optimize time allocation, helping users balance workloads efficiently

## Account security

The registration handler stores passwords only as hashes generated by PHP's
`password_hash()` API; it never saves the submitted password itself. The
`users.password_hash` database column must be `VARCHAR(255)` (or larger) to
support current and future PHP password-hashing algorithms. Login checks the
stored value with `password_verify()` and refreshes it if PHP recommends a
newer hash format.
